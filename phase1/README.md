# Phase 1 — project planning

Phase 1 defines the proposed AR Troubleshooting Companion: a company administrator provides a product manual, reviews structured troubleshooting instructions, and a later customer-facing experience helps users identify relevant appliance parts and follow approved guidance.

The original proposal selected the Breville Bambino Plus BES500 and described the architecture and procedure contract. Phase 2 implements the manual-ingestion and review workflow. Phase 3 explores still-photo part localization; the user later approved switching that experiment to existing DeLonghi Dedica-family photos and using fewer than 50 images.
